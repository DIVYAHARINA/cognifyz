# Cognifyz Internship Project: ShopEasy Ultimate

> **Where Data Meets Intelligence**

This repository contains my consolidated internship tasks for [Cognifyz Technologies](https://cognifyz.com), merged into a single, high-performance E-commerce application.

---

## 📁 Project Structure

```
cognifyz-internship/
│
├── index.html      → The Ultimate Store (Combined Level 1 & Level 2)
├── style.css       → Global premium styles (Night Mode, Poppins, Animations)
├── script.js       → Global logic (100+ Products, Auth, Cart, Filtering)
└── README.md       → Project documentation
```

---

## ✅ Unified Project Features

I have combined the requirements for both **Level 1** and **Level 2** into one seamless application:

### 🌟 Level 1 – Core Foundations
- **Modern UI**: Clean HTML5/CSS3 structure with a responsive navbar and hero section.
- **Interactive Buttons**: Theme toggles and functional cart controls.
- **Contact Form**: A validated form with instant user feedback.
- **JavaScript Essentials**: Dynamic content rendering and localized time-based greeting logic.

### 🚀 Level 2 – Advanced Enhancements
- **Bootstrap 5 Framework**: Professional grid system and offcanvas components.
- **Responsive Design**: Full mobile optimization with a sleek hamburger menu.
- **Category Filtering**: Real-time product filtering and search capabilities.
- **User Authentication**: A functional Login/Signup system using `localStorage` with persistent user profiles.
- **Inventory Management**: 100+ unique products with non-repeating high-quality imagery.

---

## 🛠️ Tech Stack
- **Structure**: HTML5
- **Styling**: CSS3 (Variables, Flexbox, Grid), Bootstrap 5
- **Logic**: JavaScript (ES6+, Local Storage)
- **Icons**: Font Awesome 6
- **Typography**: Google Fonts (Poppins)

---

## 🚀 How to Run
Simply open the root `index.html` file in your browser. All data (cart and user profiles) is stored locally in your browser's memory.
